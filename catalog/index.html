1. Что такое формат .fptools?

Формат .fptools - это стандартизированный JSON-контейнер. Он используется для обмена настройками, шаблонами, автоответами и правилами ИИ между пользователями приложения FunPay Tools.

2. Структура файла (JSON)

{
  "version": 1,
  "author": "Nickname",
  "description": "Описание пака",
  "data": {
    "templates": [...],
    "auto_responses": [...],
    "review_reply_settings": {...},
    "greeting_settings": {...},
    "feedback_bonus_settings": {...}
  }
}

3. Принцип "QR-кода" (Fault-Tolerance) при Импорте

Даже если часть файла повреждена (например, отсутствует скобка), парсер в приложении выживет. В цикле обхода данных используется блок try-catch на каждый элемент.

Алгоритм парсинга:

  1. Читаем блок data.
  2. Входим в цикл по массиву.
  3. Оборачиваем чтение каждого элемента в безопасный блок.
  4. Если 2-й элемент содержит ошибку - мы ловим Exception, пропускаем 2-й элемент, но успешно сохраняем 1-й и 3-й.
