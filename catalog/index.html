Спецификация .fptools

×

Формат .fptools — это стандартизированный JSON-контейнер для обмена настройками FunPay Tools.

Структура:

{
  "version": 1,
  "author": "Nickname",
  "description": "Описание",
  "data": {
    "auto_responses": [ { "trigger": "!привет", "response": "Да, привет!" } ],
    "templates": [ { "name": "Выдача", "text": "Ваш товар: ..." } ],
    "ai_settings": { "style": "дерзкий" }
  }
}

Принцип QR-кода (Fault-Tolerance)

Парсер в приложении/расширении должен игнорировать поврежденные ключи. Если в массиве `templates` второй элемент сломан, парсер сохраняет первый и третий. Используйте блоки try-catch на каждый элемент цикла, а не на весь файл целиком.
