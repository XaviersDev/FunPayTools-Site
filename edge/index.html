FunPay Edge: копия FunPay Tools

10.10.2026 · XaviersDev, разработчик FunPay Tools

Приложение «FunPay Edge» в RuStore (пакет ru.dengrig_denis.funpay, на телефоне подписано просто «FunPay») собрано на коде FunPay Tools. В APK посимвольно совпадают десятки внутренних строк и 29 классов с теми же полями, а упоминания автора удалены.

Совпадающие строки

Это служебные сообщения журнала, которые придуманы в FunPay Tools. На сайте FunPay их нет, сами собой они совпасть не могут. Все совпадают символ в символ, вместе с эмодзи.

Как проверить самому за 5 минут

Нужен только APK из RuStore и бесплатный декомпилятор jadx.

  1. Скачать приложение «FunPay Edge» из RuStore и открыть APK в jadx-gui.
  2. Поиск по тексту (Ctrl+Shift+F): Онлайн-пинг OK.
  3. Открыть FunPayRepository.kt на GitHub и найти ту же строку.
  4. Повторить с любой строкой из таблицы выше или открыть класс ru.dengrig_denis.funpayedge.FloodChatSettings.

Что покажет jadx: строки сидят в тех же по смыслу местах, только классы переименованы.

Упоминаний FunPay Tools, AlliSighs и funpay.tools в APK нет ни одного. Исходники FunPay Tools лежат открыто на GitHub, лицензия запрещает копирование и распространение. Даты коммитов в репозитории показывают, когда каждая строка появилась у нас.

В клоне есть и свои функции: магазин с покупками, пополнение баланса, рейтинг доверия, push от RuStore. Но основа (модели, репозиторий, тикеты, профили, журнал) взята из FunPay Tools.

Есть ли вредоносный код

Признаков не найдено. Это разбор APK без запуска, полной гарантии он не даёт.

  • Ключ входа golden_key уходит только на funpay.com.
  • На сторонние сервисы (api.funpaylitebot.com, Firebase fp-helper) уходит только ID чужого профиля, чтобы показать значок «пользуется ботом».
  • Нет загрузки кода на лету, доступа к SMS, контактам и специальным возможностям.

Итог: это не вирус, а переделанная без разрешения копия FunPay Tools, выложенная в RuStore как «FunPay Edge».
