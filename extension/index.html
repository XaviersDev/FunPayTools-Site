FP Tools - расширение для Chrome на FunPay

Полный апгрейд рабочего места: прокачанный чат с фоторедактором, умная автоматизация, массовое управление лотами, ИИ-ассистент и кастомизация интерфейса.

extension Установить в Chrome code GitHub

Chrome · Yandex · Edge · Opera · Brave  |  Устанавливается в 1 клик

🔧 Установка

Как установить FP Tools

1

Открой Chrome Web Store

Нажми Установить в Chrome - откроется страница расширения в магазине

2

Добавь расширение

Нажми Добавить в Chrome, затем подтверди установку

3

Открой FunPay

Перейди на сайт - в шапке появится новая кнопка FP Tools

4

Настрой под себя

Открой меню и включи нужные функции. Все работает мгновенно

⚡ Функции

Что умеет FP Tools

Сотни полезных инструментов, созданных специально для продавцов

mms

Максимально прокачанный чат

Уникальное меню прикрепления. Отправляйте несколько фото сразу и добавляйте текст, который уйдет одним красивым сообщением.

crop

Встроенный фоторедактор

Перед отправкой скриншот можно обрезать, выделить важное кистью или стереть лишнее ластиком прямо в окне чата.

collections

Альбомы и Лайтбокс

Несколько картинок подряд схлопываются в аккуратный альбом-мозаику. Открывайте фото в полноэкранной галерее, приближайте и листайте.

search

Поиск и Черновики

Ищите слова внутри диалога через встроенную лупу. Написанный текст никуда не пропадает при переходе в другие чаты, черновики работают идеально.

history

История покупок в чате

В меню чата сразу видно количество заказов покупателя, общую сумму и список того, что именно он у вас брал.

forum

Общий чат продавцов

Специальная вкладка для общения с другими пользователями расширения прямо на сайте. Делитесь опытом и советами.

memory

Железобетонная работа

Автоматизация переписана с нуля. 5-уровневая защита от сна позволяет фоновым процессам работать без перебоев даже при свернутом браузере.

update

Умное авто-поднятие

Расширение само читает ответ серверов FunPay и ставит таймер секунда в секунду. Никаких лишних запросов и багов. Поднимает все лоты или только с автовыдачей.

smart_toy

Передовой автоответчик

Новые триггеры при оплате и подтверждении заказа. Имитация набора текста, поддержка английских системных сообщений и интеграция с черным списком.

shield

Защита от спама

Умный антиспам предотвращает ситуации, когда бот отвечает сам себе или флудит чат одинаковыми сообщениями.

flash_on

Авто-выдача товаров

Группировка по категориям с видимым остатком. Лот сам деактивируется при нуле товаров и включается обратно при пополнении запасов.

celebration

Бонусы и уведомления

Автоматическая отправка текста, картинки или промокода за отзыв 5 звезд. Webhook-уведомления о новых событиях в Discord.

find_replace

Массовое редактирование

Точечная замена кусков текста сразу у десятков лотов через функцию Найти и заменить. Поддержка регулярных выражений RegEx.

content_copy

Улучшенное копирование

На странице любого чужого или своего лота есть кнопка Копировать. При создании своего лота вставляются абсолютно все данные без лишних пустых строк.

price_change

Продвинутый редактор цен

Кликайте на цену прямо на странице лота и меняйте ее. Добавлен предпросмотр и массовое изменение цен в процентах.

difference

Массовое управление

Выделяйте, удаляйте, дублируйте и отключайте лоты пачками. Продвинутое клонирование позволяет копировать лот сразу в несколько категорий.

import_export

Экспорт и импорт лотов

Полные резервные копии всех лотов в один файл. Импорт можно отложить на 24 часа при лимитах и продолжить позже. Конвертер лотов из Cardinal.

tag

Копирование ID заказа

Номер активного заказа в шапке страницы теперь кликабелен. Одно нажатие, и он мгновенно скопирован в буфер обмена.

auto_awesome

ИИ-ассистент в чате

Напишите черновик, нажмите Enter, и ИИ мгновенно перепишет его в вежливый профессиональный ответ. Бот сам поймет контекст разговора.

star_rate

Быстрый ответ на отзывы

Возле каждого отзыва на странице проданного лота есть кнопка Ответить. ИИ генерирует красивый ответ с упоминанием купленного товара.

inventory_2

Генератор лотов

Опишите идею своими словами. Нейросеть проанализирует другие ваши предложения и создаст готовый лот в вашем уникальном стиле.

query_stats

ИИ-Аудит магазина

ИИ изучает ваши лоты и отзывы, задает около 40 вопросов и выдает персональные рекомендации по улучшению продаж и центинг конкретно для вас.

image

Генератор изображений

Напишите текстом, что хотите видеть на превью лота, и встроенный генератор создаст стильную привлекательную картинку.

translate

ИИ-переводчик

Встроенный переводчик для названий, описаний лотов и сообщений. Все входящие сообщения не на русском переводятся прямо под оригиналом.

tune

Умная настройка интерфейса

Напишите словами убери скрепку и кнопку ИИ, и нейросеть сама снимет нужные галочки. Также есть удобный ручной каталог с предпросмотром для отключения элементов.

speed

Молниеносное меню

Новый строгий темный дизайн меню без тяжелых теней. Открывается за миллисекунды и работает мгновенно даже на слабых ПК. Вшиты локальные иконки.

palette

Темы и фоны

Галерея готовых тем применяется в один клик. Идеальная темная тема, GIF-фоны, настройка шрифтов и прозрачности. Темы работают даже на сайте техподдержки.

quickreply

Шаблоны-кнопки

Создавайте кнопки с переменными. Теперь в шаблоны можно вставлять изображения с компьютера и выбирать порядок отправки текста и фото.

people_alt

Метки и Свой-Чужой

Специальная метка в чате покажет, кто из собеседников тоже использует расширение. Кастомные цветовые метки для удобной сортировки пользователей.

auto_fix_high

Волшебная Палочка

Редактируйте любой элемент сайта в реальном времени. Меняйте цвета, скрывайте ненужные блоки и сохраняйте свой уникальный дизайн FunPay.

analytics

Статистика продаж

Глубокая аналитика за любой период. Добавлены умные задержки при загрузке огромной истории продаж для предотвращения лимитов от серверов FunPay.

store

Аналитика рынка

Сводка по категории конкурентов: количество предложений, активных продавцов, средняя цена по рынку прямо сейчас.

savings

Копилки

Ставьте финансовые цели и отслеживайте их прогресс в процентах прямо в шапке сайта. Помогает копить на мечту.

person_search

Поиск продавца

Ищите любого селлера по нику из шапки сайта. Мгновенно отображается его аватарка, выручка, отзывы, средний чек и топ категории.

timer

Таймер заказов

Обратный отсчет подтверждения у каждого оплаченного заказа. Становится красным, если до автоподтверждения осталось менее 6 часов.

manage_accounts

Аккаунты и техподдержка

Мгновенное переключение аккаунтов. Вкладка Тикеты прямо в меню расширения позволяет управлять обращениями в саппорт без перехода на их сайт.

❓ FAQ

Частые вопросы про FP Tools

FP Tools - это сокращенное название FunPay Tools, полностью бесплатного расширения для Chrome. Оно добавляет продвинутый чат, ИИ-ассистента, умную автоматизацию, управление лотами и кастомизацию интерфейса на сайт FunPay.
Нажмите Установить в Chrome, после чего откроется официальный магазин расширений. Нажмите Добавить в Chrome и подтвердите. При следующем заходе на сайт FunPay в верхней панели появится кнопка FP Tools.
Да, расширение абсолютно бесплатно. Нет никаких платных подписок, скрытых платежей или рекламы. Весь исходный код полностью открыт на GitHub.
Да, расширение стабильно работает в любом браузере на базе Chromium. Это касается Google Chrome, Яндекс Браузера, Microsoft Edge, Opera и Brave.
Код расширения открыт для всех желающих на GitHub. Программа не собирает ваши личные данные и не отправляет их на сторонние серверы. Расширение официально проверено модераторами Google при публикации в Web Store.
Расширение предлагает мощные инструменты для ПК: фоторедактор, кастомизацию тем, массовое управление лотами и аналитику. Приложение на Android имеет уникальный демпер цен, мобильный мессенджер, виджеты и может работать при выключенном экране телефона.
