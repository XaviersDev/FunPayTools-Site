🔧 Установка

Как установить FP Tools

1

Открой Chrome Web Store

Нажми «Установить в Chrome» — откроется страница расширения в магазине

2

Добавь расширение

Нажми «Добавить в Chrome» → «Добавить расширение»

3

Открой FunPay

Перейди на funpay.com — в шапке появится кнопка «FP Tools»

4

Настрой под себя

Нажми «FP Tools» в шапке и включи нужные функции — всё работает сразу

⚡ Функции

Что умеет FP Tools

100+ инструментов — выбери категорию

auto_awesome

ИИ-ассистент в чате

Напишите черновик — ИИ мгновенно перепишет в профессиональный ответ. Исправляет ошибки, добавляет эмодзи, подстраивает тон под ситуацию.

inventory_2

ИИ-генератор лотов

Опиши идею — ИИ создаст привлекательное название и описание в твоём уникальном стиле, проанализировав другие твои лоты.

image

ИИ-генератор изображений

Напишите текстом что хочешь («огненный значок, текст FIRE SQUAD») — ИИ создаст стильное превью для лота.

star_rate

ИИ-ответ на отзывы

На странице заказа — кнопка генерации вежливого ответа с упоминанием товара покупателя. Одним кликом.

translate

ИИ-переводчик

Встроенный переводчик названий, описаний и сообщений. Быстрый перевод лота на английский в один клик.

update

Авто-поднятие лотов

Автоматически поднимает предложения по таймеру. Выбери конкретные категории или только лоты с автовыдачей.

waving_hand

Авто-приветствие 2.6

Автоматически отправляет приветствие покупателям, которые пишут впервые. С Anti-Spam кулдауном.

reply

Ответы на команды 2.6

Настрой ключевые слова («!реквизиты», «/цена») — расширение мгновенно ответит нужным текстом.

rate_review

Авто-ответ на отзывы 2.6

Разные шаблоны для оценок 1–5 звёзд. Расширение отвечает само сразу после получения отзыва.

celebration

Бонус за 5★ 2.7

Автоматически отправляет бонус (текст, промокод или картинку) за пятизвёздочный отзыв покупателя.

discord

Уведомления в Discord

Webhook-интеграция: новые сообщения и заказы приходят в твой Discord-канал. С поддержкой пинга @everyone.

import_export

Экспорт и импорт лотов

Полные резервные копии всех лотов в один файл. Перенос между аккаунтами, восстановление после удаления.

content_copy

Копирование любого лота 2.7

На странице любого, даже чужого лота — кнопка «Скопировать». Данные вставятся при создании своего.

select_all

Массовое управление

Выделяй, удаляй, дублируй, включай и редактируй цены пачками. Выбор всей категории одним кликом.

difference

Продвинутое клонирование

Копируй лот сразу в несколько категорий — десятки вариаций за раз для разных серверов и регионов.

push_pin

Закрепление лотов

Закрепляй важные предложения вверху страницы профиля для привлечения внимания покупателей.

swap_horiz

Конвертер Cardinal

Переносишь лоты с Cardinal? Конвертер преобразует весь бэкап в формат FP Tools за один клик.

palette

Темы и GIF-фоны

Полный редизайн FunPay. Анимированные GIF-фоны, кастомные цвета, прозрачность, размытие. Каталог тем в Telegram-боте.

auto_fix_high

Live Styler — волшебная палочка

Кликай на любой элемент FunPay и меняй цвет, размер, скрывай блоки в реальном времени. Сохраняй свой дизайн.

quickreply

Шаблоны-кнопки в чате

Заготовки с переменными ({buyername}) и ИИ ({ai:пожелай хорошего дня}). Перемещай, перекрашивай, отключай.

label

Метки пользователей

Создавай метки с уникальными именами и цветами (мошенник, постоянный клиент). Фильтрация чатов по меткам.

emoji_emotions

Эффекты курсора и шрифты

Анимированные частицы (искры, снег). Unicode-шрифты и спецсимволы для оформления лотов.

people_alt

Опознаватель «Свой-Чужой» 2.7

Видишь метку в шапке чата, если собеседник тоже пользуется FP Tools.

analytics

Статистика продаж

Подробная аналитика за любой период: доход, средний чек, популярные товары, лучшие покупатели. Графики.

store

Аналитика рынка

Сводка по любой категории: количество лотов, продавцов, средняя цена, число конкурентов онлайн прямо сейчас.

savings

Копилки — финансовые цели

Установи цель (например 50 000 ₽) и отслеживай прогресс. Синхронизируется с балансом, видна в шапке сайта.

calculate

Калькулятор комиссий

Точная цена с учётом комиссии СБП. Видишь сразу, за сколько реально выставлен лот для покупателя.

sort

Сортировка по отзывам

Анализируй конкурентов — сортируй предложения по количеству отзывов у продавцов, не только по цене.
