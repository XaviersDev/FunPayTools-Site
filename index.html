Вопросы

Это точно бесплатно?

Да. Без подписок, скрытых платежей и рекламы.

Где хранится мой Golden Key?

Только на вашем устройстве. Ключ и куки не отправляются на сторонние серверы. В программе для Windows они лежат в папке %APPDATA%\FunPayTools.

Что выбрать: Windows, Android или Chrome?

Программа для Windows удобна, если вы весь день за компьютером. Приложение для Android работает в кармане круглые сутки. Расширение улучшает сам сайт FunPay. Их можно использовать вместе.

Windows ругается на программу, это вирус?

Нет. SmartScreen показывает предупреждение для любой новой программы без платной подписи кода. Нажмите "Подробнее", затем "Выполнить в любом случае". Это нужно один раз.

Как войти, если у меня нет Golden Key?

Нажмите "Войти через браузер": откроется страница входа FunPay, войдите как обычно, в том числе с кодом подтверждения, и FunPay Tools подхватит вход сам.

Не забанят ли меня на FunPay?

FunPay Tools работает через обычные запросы сайта, как браузер. Гарантий дать нельзя, автоматизация всегда на ваш риск, но тысячи продавцов пользуются без проблем.

Как обновиться?

Программа для Windows и приложение для Android обновляются сами. Расширение обновляет Chrome Web Store.
